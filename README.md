# Pizza Sales Analysis using SQL

> **An end-to-end SQL analytics project that explores pizza sales data to uncover customer ordering patterns, product performance, and revenue insights through real-world business queries.**

This project analyzes a pizza restaurant's sales database using SQL to answer practical business questions. The analysis is organized into **Basic**, **Intermediate**, and **Advanced** levels, demonstrating proficiency in SQL fundamentals, data aggregation, joins, window functions, and business analytics.

---

## Project Overview

Restaurants generate thousands of transactions every day. Analyzing this data helps businesses understand customer demand, optimize inventory, improve menu offerings, and maximize revenue.

This project demonstrates how SQL can be used to transform raw transactional data into meaningful business insights by solving real-world analytical problems.

# Database Structure

The project analyzes data from four relational tables:

| Table | Description |
|--------|-------------|
| **Orders** | Customer order information including date and time |
| **Order Details** | Quantity of pizzas ordered in each transaction |
| **Pizzas** | Pizza size and pricing information |
| **Pizza Types** | Pizza names, ingredients, and categories |

---

# SQL Analysis

The project is divided into three levels of business analysis.

## 🟢 Basic Analysis

- Calculate total number of orders
- Calculate total revenue
- Identify the highest-priced pizza
- Find the most commonly ordered pizza size
- Determine the top five most ordered pizza types

---

## 🟡 Intermediate Analysis

- Analyze quantity sold by pizza category
- Study hourly order distribution
- Calculate category-wise pizza distribution
- Compute average pizzas ordered per day
- Determine top revenue-generating pizzas

---

## 🔴 Advanced Analysis

- Calculate revenue contribution by pizza category
- Analyze cumulative revenue over time
- Identify top-performing pizzas within each category
- Rank pizzas using SQL window functions
- Perform advanced revenue analysis using CTEs
